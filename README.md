# Run and deploy your AI Studio app

This contains everything you need to run your app locally.

View your app in AI Studio: https://ai.studio/apps/a9b5c35c-97aa-4180-94aa-1c9c0aca883c

## Run Locally

**Prerequisites:** Node.js

1. Install dependencies:
   `bun i`
2. Run the app:
   `bun run dev`

Build the app:
`bun run build`
